# Examen Silentii article template

Template for manuscripts submitted to [Examen Silentii (ExSil)](https://examen-silentii.github.io).

## Using the template

1. Click **Use this template** to create your own copy, or download `paper.md` and `paper.bib`.
2. Write your examination in `paper.md`, keeping every section. Where a section does not apply, write "Not applicable" with a short reason.
3. Add your references to `paper.bib`.
4. Archive your test materials (code, data and instructions) in a public repository or on Zenodo, and record the DOI in the `materials` field.
5. Submit by opening an issue with the *Submit an examination* form in [examen-silentii/submissions](https://github.com/examen-silentii/submissions).

Before submitting, please read the [submission requirements](https://examen-silentii.github.io/submit/) and [policies](https://examen-silentii.github.io/policies/).
